# Schriften

- `ABeeZee-Regular.ttf` – Druckschrift, © The ABeeZee Project Authors,
  SIL Open Font License 1.1 (siehe `ABeeZee-OFL.txt`). Unverändert aus
  github.com/google/fonts übernommen.
- `grundschrift.woff2` – **Platz für die Grundschrift.** Datei unter genau
  diesem Namen hier ablegen. Solange sie fehlt, zeigt die Seite bei
  „Grundschrift“ einen Hinweis im Elternbereich und nutzt die Druckschrift.
  Bitte nur eine Schrift ablegen, deren Lizenz die Einbindung auf einer
  Webseite erlaubt.
