Über die Kuhklasse und Datenschutz

Über dieses Projekt

Die Kuhklasse ist ein privates, nicht kommerzielles Hobbyprojekt eines Elternteils zum Üben zu Hause. Sie ist kein Angebot einer Schule und keine geprüfte Lernsoftware. Die Nutzung ist kostenlos.

Haftung

Die Inhalte wurden sorgfältig erstellt. Für Richtigkeit, Vollständigkeit und Aktualität wird keine Gewähr übernommen. Im Zweifel gilt, was die Lehrkraft im Unterricht sagt.

Datenschutz

  • Keine Anmeldung, keine Konten, keine Namen. Die App fragt keine persönlichen Daten ab.
  • Kein Tracking, keine Werbung, keine Cookies, keine Analyse-Dienste.
  • Keine Anfragen an fremde Server. Schriften und Bilder liegen in der App selbst.
  • Einstellungen bleiben auf dem Gerät. Gewählte Übungen, Schrift, der Stand der Zähluhr und die Bestätigung des Begrüßungshinweises werden im Browser gespeichert (localStorage). Diese Daten verlassen das Gerät nicht und lassen sich jederzeit über die Browser-Einstellungen löschen.
  • Hosting: Die Seite wird über GitHub Pages der GitHub, Inc. ausgeliefert. Beim Aufruf verarbeitet GitHub technisch notwendige Zugriffsdaten, zum Beispiel die IP-Adresse, um die Seite auszuliefern und vor Missbrauch zu schützen. Einzelheiten stehen in der Datenschutzerklärung von GitHub (docs.github.com → Site policy → GitHub General Privacy Statement).
